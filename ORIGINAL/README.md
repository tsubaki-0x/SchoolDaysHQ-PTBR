# ORIGINAL

Esta pasta recebe **somente arquivos da instalação local do usuário**.

Nenhum `Script.GPK`, `System.GPK` ou extração original do jogo deve ser versionado neste repositório.

Estrutura esperada para a pipeline de diálogos:

```text
ORIGINAL\
├── Script_original.GPK
└── Script\
    └── ENGLISH\
        ├── 00\
        ├── 01\
        ├── 02\
        ├── 03\
        ├── 04\
        └── 05\
```

`Script_original.GPK` deve vir da própria instalação do usuário já compatível com a versão 1.02 usada pelo projeto.
