# SYSTEM

Esta pasta é reservada para arquivos auxiliares locais relacionados ao `System.GPK`.

A pipeline principal documentada neste repositório é dedicada à tradução de diálogos e escolhas em `Script.GPK`.

Modificações gráficas de interface feitas separadamente em `System.GPK` não fazem parte dessa pipeline principal e não são necessárias para reproduzir o fluxo ORS → XML → ORS → Script.GPK.

Assets proprietários extraídos do jogo e arquivos `.GPK` não devem ser versionados aqui.
