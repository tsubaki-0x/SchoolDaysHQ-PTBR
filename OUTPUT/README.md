# OUTPUT

Diretório de saída final gerado localmente.

A pipeline de diálogos gera:

```text
OUTPUT\Script.GPK
```

Ferramentas auxiliares podem gerar também uma `System.GPK` local, dependendo do fluxo usado pelo responsável pelo projeto.

Arquivos `.GPK` gerados não devem ser versionados no repositório; distribuições para usuários finais devem ser publicadas pela aba **Releases**.
